# Sentinela
### Sistema Inteligente de Prevenção de Churn Bancário – Aura Bank

## Sobre o projeto
Desenvolvido durante o Hackathon de Dados do programa **ELASTECH+**, 
na trilha de dados, com participação seletiva de candidatas.

## Equipe
Desenvolvido em equipe de 5 pessoas no Hackathon de Dados do programa 
ELASTECH+. Responsável pela modelagem preditiva, análise de dados, 
arquitetura da solução e construção dos dashboards em Power BI.

## O Problema
O Aura Bank perde 1 em cada 4 clientes por cancelamento.
Isso representa R$448.200 em receita anual em risco.

## Tecnologias
Python | SQL | Machine Learning | Power BI

## Estrutura
- `notebooks/` → Análise exploratória e modelo preditivo
- `sql/` → Queries de insight segmentado
- `data/` → Dataset simulado com 1.000 clientes
- `docs/` → Documento de arquitetura
- `powerbi/` → Painéis da Diretoria e do Analista
